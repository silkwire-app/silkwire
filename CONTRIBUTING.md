# Contributing to Silkwire

Thanks for your interest! Silkwire is in early development, so the best first step is to open an issue describing what you'd like to change before writing a large patch.

## Ground rules

- Be kind. Assume good intent.
- Keep changes focused: one idea per pull request.
- Run `swift Scripts/test.swift` before opening a pull request, and add tests for new behavior.
- Never include secrets, personal data or real conversation content in code, tests or screenshots. Use clearly synthetic examples.
